# Native projection boundary

`NativeEditorView` projects the same SQLite-backed shared Session through its generated Swift interface. The serial executor establishes a rich snapshot cursor, drains ordered range patches on subsequent reads, and obtains current shared selection resolutions before delivering owned values to MainActor. An overflow requests a fresh snapshot. Invalid cursors, malformed batches and foreign document lineage fail without changing native storage.

The projection retains shared node IDs, spans, runs, block/editor descriptors and native object identities. Attributed text carries inert shared run/node descriptors; portable style presentation belongs to DSK-1.8. A module block occupies one native `NSTextAttachment` UTF-16 unit, with distinct before/after coordinates. This mapping does not qualify image loading, table views, custom rendering or attachment editing.

Use `await view.select(range:backwards:affinity:)` to capture a durable selection before asynchronous work. Text endpoints use shared right bias; an attachment's before/after endpoints use left/right bias at its zero-width semantic position. Direction remains explicit and independent of AppKit caret affinity. Changed-node edits, deletion and history resolve the original shared anchors. Deleted, unresolvable or foreign resolutions explicitly invalidate selection; the adapter never guesses replacement semantic positions from text diffs. The authoritative resolution diagnostics remain available as `selectionResolutions`.

`projection.capture` and `projection.select` expose revision-scoped coordinates for immediate mapping. Old revisions and another view's coordinates reject. A failed shared capture leaves the prior selection intact; pending captures fail on disposal. Replacing a retained selection releases the previous shared anchor slots. Host reads and lifecycle status remain available when rich projection is unavailable; `projectionSessionFailure` is separate from the Session read result. Request `.resyncProjection` followed by `.read` to establish a fresh cursor after a projection failure.

Run `bash native/macos/scripts/check.sh projection` from `core` with the pinned Node version on PATH. It generates the existing Rust rich fixture into an actual SQLite store and executes the AppKit suite. The suite labels prepared malformed-input guards separately from real Session/native integration. The dispatcher records both CPU builds, the arm64 runtime, fixture/source/binary hashes and exact counts. Platform IME, accessibility, packaged consumers and release support remain unqualified.
