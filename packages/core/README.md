# @edit-ac/core

Reserved for the edit.ac WASM loading and transport boundary.

This private development scaffold exports an empty module. It has no editor
implementation, runtime dependencies, or released API. Build it from the
repository root with `npm run build` before importing its `dist/` entry point.

Publishing is disabled until the implementation and release gates in
[edit-ac/architecture](https://github.com/edit-ac/architecture) pass.
