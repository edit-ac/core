# Editor logo

Use `editac-mark.svg` for the edit.ac editor identity. The two original paths remain unchanged. Render the mark on transparency at 16 CSS pixels or larger, with the current foreground color; place it to the left of visible **edit.ac** text. Treat it as decorative next to that text, and give standalone meaningful uses an accessible name.

`editac-github-avatar.png` is the padded 1024 pixel external-listing variant. Both files are byte-identical copies of the canonical files in [edit-ac/docs](https://github.com/edit-ac/docs/tree/main/static/brand).

Follow the [architecture brand guide](https://github.com/edit-ac/architecture/blob/main/design/brand-guide.md) for colors, spacing, variants, provenance and regeneration. The source artwork is [CC0](https://www.svgrepo.com/svg/238902/edit-text-edit-tools).
