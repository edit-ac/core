# Package and check a third-party extension

Publishable packaging remains subject to the separate release gate. A local reusable extension exports a typed factory from its package root, declares compatible `@edit-ac/web` and `@edit-ac/core` peer versions, includes JavaScript/declarations and its Apache-2.0 license/attribution, and lists any optional asset entry explicitly. Do not bundle a second engine or rely on workspace aliases/private paths. Keep portable JSON descriptors distinct from host callbacks and credentials.

Before sharing a tarball, run `npm pack --ignore-scripts`, install it and its pinned peers into an empty directory, and compile a strict consumer resolving only those installed packages. Import with DOM/fetch access denied to establish SSR safety. Test original text/data expectations through production WASM: admission/duplicate rejection, readonly, command failure, one undo/redo, unknown-data fallback, cancellation, stale target and idempotent disposal. Keep prepared resolvers/checkers deterministic; do not record live providers or load secrets. Missing/skipped checks do not qualify support.

From this core checkout, run `node scripts/test-extension-dx.mjs --group documentation` with the pinned toolchain and a unique `EDITAC_EXTENSION_DX_OUTPUT`. The harness packs/installs authenticated artifacts, compiles the exact documented ranges, rejects stale hash/range/version/options and private imports, executes real editor outcomes and records exact counts, package hashes and teardown. It never uses workspace path aliases or mutates a package after installation. Full upstream groups remain their own evidence, not implied reruns.

[recipe-manifest.json](recipe-manifest.json) is the DOC-1.34/1.35 handoff: facade version, package versions, guide/source SHA-256 and inclusive line ranges plus expected behavior. Consumers must read it from the qualified immutable core commit and verify every pin before copying. Do not regenerate it silently to bless drift. Public-site rendering belongs to the docs owner. The manifest and documentation receipt do not authorize publication or close original platform/performance/release gates.
