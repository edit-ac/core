# edit-ac-epub-v1 import

EPUB 3.3 reflowable semantic v1, package version3.0, OCF version1.0. Single rendition, exact first uncompressed mimetype (no header extra), bounded in-memory ZIP, UTF-8 XML1.0 with namespaces and no DTD/processing instructions. EPUB2/NCX, DRM/encryption and fixed layout are unsupported; package-level encrypted/rights or fixed-layout declarations fail before semantic staging. Original immutable bytes and SHA256 remain accessible through PreparedJob under host retention policy.

Package manifest resolves local bounded relative paths (including parent references contained inside the archive); aliases/duplicate IDs/repeated spine entries/missing parts fail. Encoded/query/remote paths are outside v1 and never fetched. Required title/identifier/language/modified metadata is available in the report; additional metadata is diagnosed. Primary reading order follows the spine, independent of manifest and navigation order. A single XHTML TOC reports ordered labels, package targets and fragments; chapters report package part, original SHA256 and exact block ranges. These are provenance/report records for the conversion caller, not a new persistent navigation schema. Nonlinear chapters, unused/undeclared resources, additional navigation and unsupported wrappers remain explicit loss requiring approval. No layout or publication-byte round trip is claimed.

XHTML uses the existing editac-html inert tree whitelist, with qualified paragraphs, headings, Unicode, nested bold/italic/underline/strike/link marks, line breaks, code and lists. List IDs are scoped to chapter/chunk so separate chapters cannot merge containers. HTTP(S)/mailto text links use the shared URL policy and grant no fetch authority; local links retain original recovery and report their unsupported live-link mapping. CSS reductions, event/unknown attributes, scripts/forms/active/foreign markup, tables and inline media are diagnosed. No DOM, browser, script engine, URL loader or remote converter is used. Supported images are paragraph-isolated or body-level original PNG via the shared guarded PNG budgets and authorized AssetWork staging; metadata retains alt/title, digest, length and dimensions. Repeated references charge work but reuse staged digest identity. Failure after ingestion, cancellation, stale targets, revoked capability or denied loss approval cannot commit partial content; one shared Session insertion provides undo/redo and reopen.

Existing optional zip8.6.0 (MIT; deflate, defaults disabled), quick-xml0.41.0 (MIT; defaults disabled) and flate2 1.1.10 (MIT OR Apache-2.0; zlib-rs) are reused. New optional path dependency editac-html0.0.0 (Apache-2.0; parser/default features disabled) uses its existing serde_json1.0.152 (MIT OR Apache-2.0). No new downloaded codec, font or asset. ZIP extraction APIs remain prohibited; existing filesystem-extraction advisory caveat stays applicable. Native arm64 macOS execution and wasm32 compile are independent claims; actual platform sandbox/wiring belongs to31–36, release37. Default formats graph remains dependency-free.

Limits: inherited immutable PreparedJob input/output/deadline/memory contract; guarded package actual inflate/ratio/entry/text/node/work/pixel ceilings; XML tree depth32, attributes64, element name128, attribute value4096, diagnostics512, total prepared blocks128 and bounded debug-encoded blocks/report output. Lower supplied ingress budgets are enforced by the shared scan before mapping every package/XHTML part. Host execution ports are prepared deterministic transports; resource measurements report sampled process peak RSS, not allocation-time hard memory proof.

Primary references reviewed before adapter compilation: [W3C EPUB3.3 Recommendation, 2026-01-13](https://www.w3.org/TR/2026/REC-epub-33-20260113/) sections4 OCF,5 package/manifest/spine,6 XHTML and7 navigation; [ZIP8.6 API](https://docs.rs/zip/8.6.0/zip/); [quick-xml0.41 reader](https://docs.rs/quick-xml/0.41.0/quick_xml/reader/struct.NsReader.html). Exact already-qualified codec notices and restricted API/advisory review: architecture/evidence/format-dependencies.md CNV-1.3 and document-conversion/docx-dependencies-20261017. Codec source licenses are verified in the locked graph receipt; test fixtures are local authored inputs plus existing one-pixel PNG.
