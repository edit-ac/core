# Frozen v1 construction fixture

`seed.json` is the deterministic recipe, not a checkpoint. `mapping.mjs` constructs the exact five root maps in Yjs; `crates/editac-core/tests/schema_profile.rs` demonstrates Rust construction and the selected read projector. Both use client 11 only for local fixtures. Real peers restore a single initializer update with distinct live writer IDs.

See `architecture/specs/schema-v1.md` and `protocol-v1.md` in the sibling checkout for normative ID, initialization/epoch, atomic placement/layout, tombstone, anchor, origin and admission rules. Root names are literal, including the historical `probe` names. JS arrays map to Yrs `Any::Array`, binary relative positions to `Any::Buffer` / `Uint8Array`, nested rich text to `XmlTextRef` / `Y.XmlText`; never a string value or independently merged map fields.

For a split, create `Y.createRelativePositionFromTypeIndex(firstText, offset, -1)` and put `['split', Y.encodeRelativePosition(anchor)]` in the single `pair` entry. Rust uses `sticky_index(..., Assoc::Before).encode_v1()`. Join writes `['join']`. Validate before writing. FND-1.12 qualifies these API mappings through the real pinned Yrs/Yjs exchange harness below. Local construction and the older XML/text interop tests do not establish that qualification.

Checks: `cargo test -p editac-core --test schema_profile --locked` and `node --test tests/schema-profile.test.mjs`, then original FND-1.11 canonical conflict and interop checks. No providers, recording, credentials or production transport are involved.

`exchange.mjs`, `crates/editac-core/tests/schema_interop.rs` and `tests/schema-interop.test.mjs` qualify the exact frozen mapping with 13 cases and both initializer languages. Moves, deletes, overlapping Unicode edits and split/join descriptors are authored in both languages. Both projectors compare marked visible/recovery spans, atomic placements, original nested text IDs and binary anchors, under six duplicate/reverse arrival schedules and checkpoint restore. Fresh restored peers also receive missing operations via state-vector deltas. Anchors retain original source identity; projected ownership and hidden recovery status are explicit. Pin inspection of Yjs `_item.id` is fixture-only; it is not a public production API.

Run `cargo test -p editac-core --test schema_interop --locked`, then `node --test tests/schema-interop.test.mjs` with Rust 1.97.1, matching rustdoc, Node 24.19.0 and the committed lockfiles. Each check invokes the actual other-language bridge. Temporary artifacts are removed on normal exit; set `EDITAC_SCHEMA_INTEROP_OUTPUT` to retain updates, anchors and canonical JSON for evidence. The profile envelope is checked before trusted fixture update application; this does not implement untrusted-update validation, durable storage, networking, WASM loading or arbitrary ownership pairs.
